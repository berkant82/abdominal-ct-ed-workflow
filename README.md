# Diagnostic Yield and Workflow Timing of Abdominal CT
## in Emergency Department Patients with Non-Traumatic Abdominal Pain

## Authors
Berkant Ozturk, Ayfer Keles, Sema Ozturk,
Muhammet Hacimustafaoglu, Ahmet Demircan

## Description
Single-center prospective observational study.
n = 244 emergency department patients.
Data collected: May-August 2016.
Institution: Aksaray University Training and Research Hospital, Turkey.

## Files
- analysis_clean.R : Statistical analysis script
- data/berkant_abdomen_veriset.csv : De-identified dataset (244 x 77)

## Requirements
R (>= 4.0), packages: tidyverse, irr
